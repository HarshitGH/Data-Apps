# Data Profiler

A local, browser-only CSV profiler. Open `index.html`, upload a CSV, and the app will infer column types and build:

- dataset overview and preview
- categorical and numerical column profiling
- numerical buckets for histogram-style distributions
- bivariate scatter, grouped bar, and cross-tab charts
- switchable bivariate chart modes: auto, bar, line, and scatter
- dedicated correlation tab with selectable numeric columns, ranked strongest relationships, and an improved heatmap
- row-by-column pivot distribution with count, sum, average, min, max, row-total %, and column-total %
- data quality table for missing values, distinctness, and numeric stats

No installation is required. Everything runs in the browser against the uploaded file.
